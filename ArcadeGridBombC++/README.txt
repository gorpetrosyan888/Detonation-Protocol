# UE5 Grid-Based Arcade Template

## Description

A grid-based arcade gameplay template built with Unreal Engine 5 and C++.

This project provides a foundation for creating arcade-style games with grid movement, bomb mechanics, destructible environments, and level progression systems.

---

## Features

- Grid-based movement system
- Bomb placement system
- Explosion mechanics
- Destructible blocks
- Level timer
- Enemy counter
- Level save system
- Built with C++

---

## Engine Version

Unreal Engine 5.6

---

## Controls

### Movement
- W — Move Forward
- A — Move Left
- S — Move Backward
- D — Move Right

### Actions
- Space — Place Bomb

---

## Project Structure

Content/
- Characters
- Grid System
- Bomb System
- Level Logic
- Save System
- UI

Source/
- UI
- Structural Assets/Main GameInstance, SaveLevel
- Public/Bomb, Enemy, NextLVL, Wall, etc..

---

## Installation

1. Download the project files
2. Open the `.uproject` file
3. Generate Visual Studio project files if necessary
4. Build the project
5. Press New Game
